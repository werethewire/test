# Word Rain

単語がランダムなタイミング・サイズ・位置で画面上から落ちてくるブラウザアプリ。
語をポジティブ / ネガティブ / 中立に自動判定して色分けし、**ネガティブ語だけが画面下に積み上がる**。
ポジティブと中立は画面下に着いたところで消える。積み上がったネガティブ語が指定個数に達すると、
**指定の映像と音声を再生**する。

```
word-rain/
  index.html      画面と UI
  styles.css
  app.js          落下・堆積・判定・トリガー
  sentiment.js    極性辞書（編集して語を足せる）
  wordsource.js   単語の供給源（内蔵 / テキスト / Mastodon / X）
  x_proxy.py      X API 用ローカルプロキシ（X ソースを使うときだけ必要）
```

## 起動

`index.html` をブラウザで直接開くだけで動く（`file://` で可）。外部依存なし。

ローカルサーバ経由で開きたい場合:

```bash
python -m http.server 8123 --directory "I:/マイドライブ/ClaudeCode-application/word-rain"
```

## 公開する

ビルド不要の静的サイトなので、フォルダをそのまま置けば動く。**先に公開用のコピーを作る:**

```bash
powershell -ExecutionPolicy Bypass -File "I:/マイドライブ/ClaudeCode-application/word-rain/build-dist.ps1"
```

`dist\` に公開して良い 7 ファイルだけがコピーされる。`token.txt` を除外し、Bearer トークンらしき
文字列が混ざっていないか検査してから終わる。**`token.txt` を手でアップロードしないこと** —
ホスティング上のファイルは誰でもダウンロードできるので、そのままトークンの流出になる。

### 方法 A: ドラッグ&ドロップ（アカウント作成だけ・CLI 不要）

1. <https://app.netlify.com/drop> を開く
2. `dist` フォルダをページにドラッグする
3. `https://<ランダム名>.netlify.app` が即発行される。Site settings から名前を変えられる

Cloudflare Pages（<https://pages.cloudflare.com> → Upload assets）でも同じ手順で置ける。

### 方法 B: GitHub Pages（git で更新したい場合）

このマシンには `git` はあるが `gh` は入っていないので、リポジトリはブラウザで作る。

1. GitHub で空のリポジトリを作る（例 `word-rain`、README は追加しない）
2. 以下を実行する

```bash
cd "I:/マイドライブ/ClaudeCode-application/word-rain"
git init -b main
git add .
git commit -m "Word Rain"
git remote add origin https://github.com/<ユーザー名>/word-rain.git
git push -u origin main
```

3. リポジトリの Settings → Pages → Source を `main` / `/ (root)` にする
4. 数十秒で `https://<ユーザー名>.github.io/word-rain/` が開く

`.gitignore` で `token.txt` と `dist/` は除外済み。

### 公開後に更新するとき

ブラウザは `app.js` などをキャッシュするので、ファイルを更新したら `index.html` の
`?v=2` を `?v=3` のように上げる。これで閲覧者に確実に届く。

### 公開したときの各ソースの可否

| ソース | 公開ページで | 備考 |
|---|---|---|
| 内蔵 | ✅ 動く | |
| テキスト | ✅ 動く | |
| Mastodon | ✅ 動く | HTTPS でも CORS が通る |
| X | ⚠️ 閲覧者自身の PC で `x_proxy.py` を動かしている場合のみ | ページ側に注意書きが自動で出る |

映像・音声はローカルのファイル選択なので、閲覧者それぞれが自分の手元のファイルを指定する。
サーバにアップロードされることはない。スマホでは自動再生が止められることがあるが、
その場合はオーバーレイに「タップで再生」と表示され、タップすると再生が始まる。

## 操作

パネルの各セクションは見出しをクリックで開閉する。開始・堆積をクリア・全リセットの行は
常にパネル下端に貼り付いている。`H` キーでパネル全体を開閉。

| | |
|---|---|
| 落下速度 | 10〜800 px/s。再生中でも即反映。語ごとに ±35% ほどの個体差が付く |
| 出現間隔 最短 / 最長 | この範囲の乱数で次の語が出る。両方 30ms 前後にすると豪雨になる |
| 文字サイズ 最小 / 最大 | 語ごとにこの範囲でランダム |
| ネガティブ到達数の閾値 | 画面下に着いたネガティブ語がこの数に達するとトリガー発火 |
| 映像 / 音声ファイル | 発火時に再生するファイル。片方だけでも可 |
| 堆積をクリア | 積み上がりだけ消す |
| 全リセット | 積み上がり・カウンタ・発火状態を全部戻す |

映像も音声も未指定のまま発火した場合は、赤フラッシュ + ビープ音のフォールバックが 2.5 秒鳴る。
動作確認は「トリガーをテスト再生」ボタンで閾値に関係なく行える。

## 画面下に着いたときの振る舞い

極性ごとに 3 通りから選べる。既定は **ネガティブ = 積み上がる / ポジティブ = 消える / 中立 = 消える**。

| | |
|---|---|
| 積み上がる | 先に積まれた語の上に乗って、画面下から上へ溜まっていく |
| 下段に重なる | 積み上がらず、画面下の一行に重なって残る |
| 消える | 画面下端で 0.4 秒かけて沈みながらフェードアウトする |

積み上がりは画面幅を 4px 刻みの列に分けた高さマップで判定していて、落ちてきた語は自分が跨ぐ列の
いちばん高い表面の上に乗る。テトリスと同じ規則なので、幅の広い語が乗ると下に隙間ができる。
上端まで届くと新規の出現が止まり、ステータス行に通知が出る（「堆積をクリア」で再開）。

「消える」語は堆積を無視して画面下端まで落ちる。積み上がったネガティブ語の上を通り抜けていく。

## フォント

パネルの「文字」セクションで選ぶ。

- **プリセット** — 游ゴシック / メイリオ / MS ゴシック / 游明朝 / MS 明朝 / BIZ UDゴシック /
  UD デジタル教科書体 / HG創英角ポップ体 / Impact / Georgia / Consolas
- **カスタム指定** — `font-family` の文字列を直接書く（例: `"Zen Maru Gothic", sans-serif`）。
  OS にインストール済みのフォントならこれで指定できる
- **フォントファイル** — `.ttf` / `.otf` / `.woff` / `.woff2` を読み込む。インストール不要
- **太さ** — 300 / 400 / 600 / 800 / 900

フォントを変えると落下中・堆積中の語も含めて幅を測り直すので、途中で切り替えてもレイアウトは崩れない。

## 極性の判定

`sentiment.js` が次の順に見て、当たった段階で確定する。

1. **完全一致辞書** — 日本語 約 700 語 / 英語 約 350 語 / 絵文字。
   カタカナをひらがなに寄せた鍵でも引くので「ウザい」「うざい」の両方が当たる
2. **活用語尾を落として再照合** — だるかった → だるい、疲れました → 疲れ
3. **否定形の反転** — 良くない → ネガ、悪くない → ポジ、危険ではない → ポジ。
   語幹の極性が決まる場合だけ反転するので、「少ない」「情けない」「くだらない」は壊れない
4. **形態素の重み付き合計** — 強い手がかり（死・殺・痛・悲・悪 …）は 2 点、弱い手がかり（害・遅・危 …）は 1 点。
   以前は「最初の 1 件で打ち切り」だったため **悪夢** が「悪 −1 と 夢 +1」で相殺されて中立になっていた
5. **接頭辞・接尾辞** — 日本語の `不・無・非・未`、英語の `un-` `dis-` `-less`。
   `未明` `無料` `不動産` のような例外は辞書で除外している

### 感度

パネルの「判定」セクションで切り替える。既定は**敏感**。

| | |
|---|---|
| 厳格 | 1〜2 のみ。辞書に載っている語だけ色分けする。誤判定を出したくないとき |
| 標準 | 1〜4。弱い手がかりは半分の重みで数える |
| 敏感 | 1〜5 すべて。取りこぼしを減らす（既定） |

同じセクションの「語を試す」欄に単語を入れると、その場で判定結果が出る。

### 精度

`sentiment-test.html` をブラウザで開くと、ラベル付きの語で実測できる。
語を書き換えれば自分の用途で測れるので、辞書を育てるときはここを見ながら進める。

同梱のテストセット（ネガ 70 / ポジ 70 / 中立 90 語）での実測値:

| 感度 | ネガ再現率 | ネガ適合率 | ポジ再現率 | 中立の正解率 |
|---|---|---|---|---|
| 厳格 | 64.3% | 100% | 90.1% | 100% |
| 標準 | 85.7% | 100% | 94.4% | 100% |
| 敏感 | 100% | 100% | 100% | 100% |

ただしこのセットの語はほぼ辞書に登録済みなので、**未知語に対する性能はこれより低い**。
辞書に無い語だけ 124 語で測ったときは、敏感で ネガ再現率 64.3% / 適合率 90% だった。

Mastodon の実データ 783 語では、ネガ判定される語は 厳格 2.6% → 敏感 5.0%。
`台風 暴風 避難 被害 犯罪 悲鳴 負傷 地震 赤字 借金 事故 猛暑` などが拾えている。
**実際の SNS 投稿は大半が中立**なので、閾値は 10〜20 個あたりから試すとよい。

### 辞書を足す

実行中に足す:

```js
Sentiment.addWords('negative', ['納期', '棚卸', 'レビュー待ち']);
```

恒久的に足すなら `sentiment.js` の `NEG_WORDS` / `POS_WORDS` を編集する。
**単漢字を形態素リストに足すのは慎重に** — 過去に `圧` で気圧・電圧、`冷` で冷蔵庫、
`信` で信号、`違` で違う、`進` で進路 を巻き込んだ。2 字以上の語として辞書に入れる方が安全。

判定は語単位なので、皮肉・比喩・文脈は取れない。そこは割り切った仕様。

## 単語ソース

**内蔵** — 約 150 語のプール。トークン不要で即動く。デフォルト。

**テキスト** — 貼り付けた文章を分かち書きして使う。日本語は `Intl.Segmenter` で分割し、
URL・メンション・記号・助詞・ストップワードを落とす。

**Mastodon** — 公開タイムラインを 10 秒間隔で取得する。**認証もプロキシも不要**で、
ブラウザから直接叩ける。既定は `mstdn.jp`（日本語の投稿が多い）。

> インスタンスによっては CORS を許可しておらず使えない。動作確認済み: `mstdn.jp` / `fedibird.com`。
> `mastodon.social` は公開タイムラインの匿名取得を拒否する（422）、`pawoo.net` は CORS 不可。

**X** — `x_proxy.py` 経由で X の直近検索を取得する。

### X を使う場合

ブラウザから `api.x.com` を直接叩くのは CORS で不可能で、Bearer トークンをページに
埋め込むことにもなる。そのため取得は Python プロセスが行い、本文テキストの配列だけを返す。

```bash
setx X_BEARER_TOKEN "AAAA..."
```

新しいターミナルを開いてから:

```bash
python "I:/マイドライブ/ClaudeCode-application/word-rain/x_proxy.py"
```

`127.0.0.1:8787` で待ち受ける。トークンは環境変数の代わりに同じフォルダの `token.txt` でもよい
（`Bearer ` 付きで貼っても、前後に引用符が付いていても通る）。

**取得できないときは「接続を診断」ボタンを押す。** プロキシが実際に X を叩いて、原因を日本語で返す。

| 返ってくるもの | 意味 |
|---|---|
| トークンが読めていません | 環境変数も token.txt も無い。プロキシは起動している |
| トークンが無効です (401) | トークンを取り直す |
| 権限がありません (403) | 後述の有料 tier の問題 |
| レート制限です (429) | 待つ |
| プロキシに接続できません | `x_proxy.py` が起動していない |

> **重要**: `/2/tweets/search/recent` は X API の**有料 tier のエンドポイント**。
> 無料枠のトークンでは 403 が返り、これはコード側では解決できない。
> ライブのテキストを流したいだけなら **Mastodon ソース（認証不要）** を使うのが早い。

## 自動化フック

`window.WordRain` から内部状態に触れる（`sim` / `cfg` / `spawn` / `update` / `fire` / `resetAll` …）。

```js
WordRain.cfg.speed = 400;
WordRain.cfg.behavior.neutral = 'bottom';   // 'pile' | 'bottom' | 'vanish'
WordRain.fire();                            // 手動で発火
```
